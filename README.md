# 창업 지원사업 지도

https://map.pensieve.kr

전국 창업·지원사업 공고를 시도별 지도와 필터로 찾아보는 정적 페이지입니다.

- `index.html` — 지도와 목록 화면 (시도 경계: 통계청 2013, southkorea-maps)
- `data.json` — 마감 전 공고 데이터. 이 파일만 바꾸면 화면이 갱신됩니다.
- 익명 이용 통계는 PostHog로 모읍니다 (개인정보 수집 없음).

## 데이터 갱신

```
python3 tools/update_data.py 새행.json          # 노션 행을 data.json에 합침 (공고 URL 기준, 마감 지난 공고는 뺌)
python3 tools/update_data.py 전체행.json --full  # 마감 전 공고 전체로 다시 만듦
```

입력은 노션 지원사업 DB 행 배열(사업명·주관기관·지역·신청 대상·유형·금액·마감일·요약·공고 URL).
시도와 지원 형태는 스크립트가 낱말로 분류한다. 공고 수집 루틴이 회차마다 이 스크립트를 돌리고 main에 푸시한다.

## 공고 제보

지도의 '없는 공고 알려주기'는 노션 공개 양식으로 이어지고, 제보는 노션 운영 › 지원사업 관리 › '공고 제보' 표에 쌓인다.
